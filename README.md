# motabi

藻旅 — an alga's journey. Moves a running [marimo](https://github.com/marimo-team/marimo)
notebook kernel to the compute its cells need (an HPC site, a GPU node) and brings it back,
with the notebook's dataflow graph as the workflow and independent cells run as parallel
branches.

Design: [DESIGN.md](DESIGN.md). Nothing is implemented yet.
